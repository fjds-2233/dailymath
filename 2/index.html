定义：①若定义域内任意 x 满足 f(f(x))=x，则称函数 f(x) 为对合函数.②若函数 f(x) 在区间 I 上有定义，∀ x₁, x₂∈ I，f((x₁+x₂)/2)≤ (f(x₁)+f(x₂))/2，则称 f(x) 为区间 I 上的凸函数.③对 f(x) 的导函数 f'(x) 再次求导，得到的函数称为 f(x) 的二阶导函数，记作 f''(x). 若 f''(x) ≥ 0 在区间 I 上恒成立，则称 f(x) 在区间 I 上是凸函数.设函数 f(x) = ((1-xᵖ)/(1+λxᵖ))^(1/p) (λ > -1, p > 1), x ∈ (0,1).（1）当 p > 1 时，证明：y = xᵖ 在区间 (0,1) 上为凸函数.（2）判断函数 f(x) 是不是对合函数？若是，请证明，并指出 f(x) 的单调性；若不是，请举出反例.（3）结合定义②，设 x₁, x₂ ∈ (0,1), x₁ ≠ x₂, 满足 f(x₁) ≥ x₂, f(x₂) ≤ x₁.（i）证明：当 λ > 0 时，x₁ᵖ + x₂ᵖ < 1；当 -1 < λ < 0 时，x₁ᵖ + x₂ᵖ > 1.（ii）当 λ > 0 时，证明：x₁ + x₂ < 2^((1-p)/p).

3.（3）结合定义②，设 x₁, x₂ ∈ (0,1), x₁ ≠ x₂, 满足 f(x₁) ≥ x₂, f(x₂) ≤ x₁.（i）证明：当 λ > 0 时，x₁ᵖ + x₂ᵖ < 1；当 -1 < λ < 0 时，x₁ᵖ + x₂ᵖ > 1.（ii）当 λ > 0 时，证明：x₁ + x₂ < 2^((1-p)/p).
答案：（1）证明：因为 y = xᵖ, x ∈ (0,1), p > 1, 所以 y' = px^(p-1), y'' = p(p-1)x^(p-2) ≥ 0. 所以 y = xᵖ 在 (0,1) 上为凸函数.（2）证明：因为 f(f(x)) = f(((1-xᵖ)/(1+λxᵖ))^(1/p)) = (((1-(1-xᵖ)/(1+λxᵖ))/(1+λ((1-xᵖ)/(1+λxᵖ))))^(1/p) = (((1+λ)xᵖ)/(1+λ))^(1/p) = x, 所以 f(x) 是对合函数. 令 g(x) = [f(x)]ᵖ, 有 g'(x) = (-px^(p-1)(1+λxᵖ) - (1-xᵖ)λpx^(p-1))/((1+λxᵖ)²) = (-p(1+λ)x^(p-1))/((1+λxᵖ)²). 因为 λ > -1，p > 1，所以当 x ∈ (0,1) 时，g'(x) < 0。所以 t=g(x) 在 (0,1) 上单调递减，而函数 φ(t) = t^(1/p) 在 (0, +∞) 上单调递增，故函数 f(x) 在 (0,1) 上单调递减；(3) 证明：(i) 方法一：由 (2) 知 f(x) 为对合函数，则 f(f(x₁)) = x₁。因为 f(x₁) ≥ x₂，由 (2) 知 f(x) 在 (0,1) 上单调递减，因为 x₁，x₂ ∈ (0,1)，x₁ ≠ x₂，所以 f(f(x₁)) ≤ f(x₂)，即 x₁ ≤ f(x₂)。又 f(x₂) ≤ x₁，所以 x₁ = f(x₂)，即 f(f(x₂)) = f(x₁) = x₂。由 f(x₁) = x₂，两边取 p 次幂，可得 x₂ᵖ = (1 - x₁ᵖ)/(1 + λx₁ᵖ)，即 x₁ᵖ + x₂ᵖ + λx₁ᵖx₂ᵖ = 1。设 A = x₁ᵖ > 0，B = x₂ᵖ > 0，则 A + B = 1 - λAB。当 λ > 0 时，λAB > 0，A + B = 1 - λAB < 1，即 x₁ᵖ + x₂ᵖ < 1；当 -1 < λ < 0 时，λAB < 0，A + B = 1 - λAB > 1，即 x₁ᵖ + x₂ᵖ > 1。（ii）设 h(t) = tᵖ ， t ∈ (0, 1) ， p > 1 ，由（1）知 h(t) = tᵖ 在 (0, 1) 上为凸函数，则由②，对任意 x₁, x₂ ∈ (0, 1) ， h((x₁+x₂)/2) ≤ (h(x₁)+h(x₂))/2 ， 即 ((x₁+x₂)/2)ᵖ ≤ (x₁ᵖ+x₂ᵖ)/2 . 因为 p > 1 ， 所以函数 h(t) = tᵖ 在 (0, 1) 上严格单调递增，对上述不等式两边同时开 p 次方，得 (x₁+x₂)/2 ≤ ((x₁ᵖ+x₂ᵖ)/2)^(1/p) . 因为 x₁ ≠ x₂ ， p > 1 ， 所以 (x₁+x₂)/2 < ((x₁ᵖ+x₂ᵖ)/2)^(1/p) . 根据（i）可得 λ > 0 时， x₁ᵖ + x₂ᵖ < 1 ，所以 (x₁+x₂)/2 < (1/2)^(1/p) ， 所以 x₁ + x₂ < 2^(1-(1/p)) . 先想再看 · 空格键也能显示

函数的定义

记忆用时：约 3 分钟
1要点 1
凸函数判据是 f″(x)≥0 恒成立，先算二阶导再定号。
2要点 2
对合函数：把 f(x) 代回 f 中，化简出 x 即证成立。
3要点 3
λ 定号：由 x₁ᵖ+x₂ᵖ+λx₁ᵖx₂ᵖ=1 判断和与 1 的大小。
4要点 4
凸函数：f″(x) ≥ 0，图形下凸，割线始终在曲线上方。
5要点 5
对合函数 f(f(x))=x，图象关于直线 y=x 对称。
6要点 6
若 f 严格递增且 f(f(x))=x，则 f(x)=x 成立。

通用模型
1
数列的通项公式和前n项和公式在解题中起到变量代换作用,而a1和d是等差数列的两个基本量。
2
等差数列的通项公式及前n项和公式共涉及五个量a1,an,d,n,Sn,知其中三个就能求另外两个。
3
涉及等比数列的单调性与最值的问题,一般要考虑公比与首项的符号对其的影响.
4
等比数列中有五个量a1,n,q,an,Sn,一般可以“知三求二”,通过列方程(组)便可迎刃而解.
