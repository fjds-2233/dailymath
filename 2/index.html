三角函数 · 图象变换 · 值域包含
已知函数 f(x) = 4 sin x·cos(x + φ) + √3，0 < φ < π，定义域为 R。
（1）若 f(x) 为偶函数，求 φ 的值；
（2）若 φ = π/3，关于 x 的方程 f(x) = a 在 [0, π/4] 上有两个不同的实数解，求实数 a 的取值范围；
（3）若 φ = π/3，将 f(x) 的图象向右平移 π/12 个单位长度，再把所得图象上所有点的横坐标变为原来的 2/3、纵坐标不变，得到 g(x)。函数 h(x) = m f(x)（x ∈ R，m ≠ 0），若对任意 x₁ ∈ [π/6, π/3]，总存在 x₂ ∈ [0, π/3]，使得 h(x₁) = g(x₂)，求实数 m 的取值范围。
答案：（1）φ = π/2；（2）a ∈ [√3, 2)；（3）m ∈ [−√3/3, 0) ∪ (0, 2√3/3]

苏教版·必修一 第7章《三角函数》7.3 三角函数的图象和性质 · 考向：化简为 y=Asin(ωx+φ)
【三角·偶函数】f 为偶函数 ⇔ 相位 φ = π/2 + kπ（k∈Z），再由 0<φ<π 定值。
苏教版·必修一 第7章《三角函数》7.3 · 考向：由奇偶性求参数
【三角·图象变换】平移只动 x（右移 π/12 写成 2(x−π/12)）；横坐标变 2/3 即 x 乘 3/2。
