概率 · 随机游走 · 方差
一个质点在随机外力的作用下，从原点 O 出发在数轴上移动，每次向左或向右移动一个单位且相互独立。已知向右移的概率为 3/5，向左移的概率为 2/5。设该质点移动 n 次后在数轴上对应的数为随机变量 ξₙ，则 ξₙ 的方差 D(ξₙ) = ______（用含 n 的式子表示）。
答案：24n/25

知识点 · 易错点
【概率·二项分布】X ~ B(n,p)：E(X) = np，D(X) = np(1−p)。
苏教版（2019）·选择性必修第二册 第8章《概率》
【方差性质】D(aX + b) = a²D(X)——系数要平方，加减常数不影响方差。
苏教版（2019）·选择性必修第二册 第8章《概率》
【位移】ξ = 2X − n ⇒ D(ξ) = 4D(X)，把随机游走的方差转成二项分布的方差。
