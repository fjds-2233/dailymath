经验回归方程 · 样本中心点 · 残差
下表提供了某厂进行技术改造后生产产品过程中记录的产量 x（单位：t）与相应的生产能耗 y（单位：t 标准煤）的几组数据：
x / t3456
y / t 标准煤2.53m4.5
根据散点图分析知 x 与 y 线性相关，且求得经验回归方程为 ŷ = 0.7x + 0.35，则（　　）
A.x 与 y 负相关
B.m = 3.85
C.回归直线过点 (4.5, 3.5)
D.x = 6 时的残差为 0.05
答案：C
  1. 斜率 0.7 > 0，x 与 y 正相关，A 错；
  2. 回归直线必过样本中心点 (x̄, ȳ)：x̄ = (3+4+5+6)/4 = 4.5，ȳ = (2.5+3+m+4.5)/4 = (10+m)/4，代入 ŷ = 0.7x + 0.35 得 (10+m)/4 = 3.5，解得 m = 4，B 错；
  3. m = 4 时 ȳ = 3.5，直线过 (4.5, 3.5)，C 对；
  4. x = 6 时 ŷ = 4.55，残差 = 4.5 − 4.55 = −0.05，D 错。
